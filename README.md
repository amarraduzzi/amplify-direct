# Amplify Direct
Site builder for restaurants. Astro + Tailwind, static, Cloudflare Pages.

- `npm install`, `npm run dev`, `npm run build` (output `dist/`)
- Cloudflare Pages: build command `npm run build`, output directory `dist`
- Config and domain: `src/config.ts` (`live: false` keeps the site on noindex)
- Context for Claude: see `CLAUDE.md`
